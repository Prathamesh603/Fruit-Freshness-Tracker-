# Original download

`AgricultureDataset.zip` is the original 1.01 GB Zenodo archive. During transfer its name ends in `.partial`. The downloader verifies the publisher's MD5 and byte count before using it. Image data and archives are ignored by Git; download URL, hashes, scripts, class maps and audit reports provide provenance.

Only the nine-fruit subset is extracted elsewhere. Keeping this ZIP allows us to rebuild the subset without another network download.
