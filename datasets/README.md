# Project datasets

Start with [fruit13/README.md](fruit13/README.md). That folder contains the expanded
13-fruit data collection, source records, downloaded images, annotation inventories,
quality checks, and instructions for the next training agent.

The existing `../ml/data/` belongs to the completed three-fruit experiment. Its
splits and results remain unchanged. The new collection is not installed in an app.

The user-supplied Bohni version 13 archive is audited separately in
[bohni-v13/README.md](bohni-v13/README.md). Its compact mapped detection subset and
[measured status](bohni-v13/reports/STATUS.md) do not replace the preserved first experiment.
