# Classic Plus updates

## 1.1.0-classic-plus, version code 2

Smaller image ID badges scale from7to11sp according to the box's shorter side.
Padding is reduced to2dp, and labels sit above or beside boxes when space allows.
Detail-card IDs remain readable at their original size. No model weights,
preprocessing or detection settings changed.

Install apk/Fruit-Lens-Classic-Plus-v1.1-arm64.apk, also copied to the parent
Classic apk folder. Previous APKs remain available.
