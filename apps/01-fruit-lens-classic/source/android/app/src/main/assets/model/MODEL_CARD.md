# Smart Fruit reference classifier

Local evaluation candidate. No independent accuracy evaluation or validated threshold.

Source revision: 200d8dffb48679567777a6ab5adc1d87eeea1c88

The notebook rescales RGB pixels by 1/255 and trains a MobileNetV2-based classifier at 96x96. Its validation path/provenance requires independent auditing; repository claims are not app metrics. Output is nine combined fruit/condition categories. Color alone does not establish condition.
