# Detector training experiments

`yolov8n-fruit9-v1/` is the requested first YOLOv8 experiment using the nine fruit
types with locally collected detection boxes. This area is separate from the
completed freshness classifier in `ml/` and the preserved Classic app in `apps/`.

Read the experiment README and its generated model card before using weights.
Training completion is not a claim of reliable detection for every class.
