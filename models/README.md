# Model catalog

Immutable model versions, grouped by Classic, custom detectors and custom classifiers. Start at ../PROJECT_GUIDE.md. catalog.json records exact files/hashes. Git LFS tracks binary weights; clone with Git LFS installed and run git lfs pull. Each model README explains its data, input/output, accuracy limits, parameters and training/code location. Never put a new version into an older version folder. New deployment formats may be added only with verification and recorded hashes. Classic source assets remain the preserved reference.
